# Mundo Pokémon - Interface Web Técnica

Projeto acadêmico individual de desenvolvimento de interface web moderna, semântica, responsiva e acessível (WCAG 2.2 AA), utilizando HTML5, CSS3 e JavaScript Vanilla.

---

## 🎯 Objetivo e Público-Alvo
- **Tema:** Catálogo Técnico e Dashboard de Espécimes Pokémon.
- **Público-Alvo:** Estudantes, entusiastas e pesquisadores de dados de jogos interessados em consultar atributos biométricos, status de combate e linhagens regionais.

---
